# Stellenkompass

A personal job radar for Germany, built for me and a few friends.

- A daily scan collects open roles from public job sources (company career boards and open job APIs).
- A small web app shows the roles with filters for city, English-friendly, remote and type (full-time, working student, internship).
- Each person tracks their own applications in their browser. No login, no accounts, no payments.

Status: v1 live (scanner, web app, daily deploy). See [docs/PLANS.md](docs/PLANS.md) for the plan and [docs/CHECKLIST.md](docs/CHECKLIST.md) for progress.
